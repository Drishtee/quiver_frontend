## HOW TO USE THIS DOCUMENT

Every illustration prompt below is structured as:

1. **STYLE ANCHOR** (copy-paste from Section 1 — prepend to EVERY prompt)
2. **SCENE PROMPT** (unique per illustration)
3. **COLOR LOCK** (exact hex codes to enforce)
4. **NEGATIVE PROMPT** (what to exclude — append to every prompt)
5. **TECHNICAL SPEC** (dimensions, aspect ratio, output format)

**Workflow per image:**
```
Final Prompt = [STYLE ANCHOR] + [SCENE PROMPT] + [COLOR LOCK] + [NEGATIVE PROMPT]
```

## 1. STYLE ANCHOR (Prepend to ALL prompts)

### Master Style Prefix

Copy this EXACTLY before every scene prompt:

```
Flat vector illustration, modern minimal Indian startup style, clean geometric shapes with soft rounded corners, limited color palette, slight grain texture overlay, no outlines, filled shapes only, soft ambient shadows, warm and optimistic mood, South Asian cultural context, characters with brown skin tones wearing Indian attire (kurta, saree, salwar kameez, business casual), simple facial features with dot eyes and subtle smiles, no realistic faces, semi-urban Indian setting, transparent background, isolated composition with no cropping, centered subject, white space around edges, illustration for a mobile app UI
```

### Master Negative Prompt

Append this EXACTLY after every scene prompt:

```
--no text, words, letters, numbers, logos, watermarks, signatures, realistic faces, photorealistic, 3D render, photograph, stock photo, clipart, cartoon, anime, manga, pixel art, sketch, pencil drawing, hand drawn, doodle, grunge, dark mood, violent, scary, western setting, caucasian features, corporate office, suit and tie, iPhone, Apple products, luxury items, complex backgrounds, busy composition, gradient mesh, drop shadows, bevels, glossy effects, chrome, metallic
```

### Color Palette Lock

Use ONLY these colors in every illustration (specify in prompt):

```
Primary palette: deep navy blue (#2E3192), dark navy (#1A1F6E), vibrant green (#00A651), amber yellow (#F59E0B), dark amber (#D97706), white (#FFFFFF), light warm gray (#F3F4F6), medium gray (#9CA3AF)
```

### Naming: `gfx-[section]-[number][variant]-[name].png`

### AI Generation Settings (Recommended)

| Setting | Value |
|---------|-------|
| **Model** | DALL-E 3 or Flux 1.1 Pro or Midjourney v6 |
| **Style** | Natural (DALL-E) / `--style raw` (Midjourney) |
| **Quality** | HD / High |
| **Output format** | PNG with transparency |
| **Post-processing** | Remove background if not transparent, run through TinyPNG for compression |
| **Consistency check** | After generating 3-4 images, compare side by side. If style drifts, regenerate with tighter style anchor wording |

### Batch Generation Tips

1. **Generate all icons in one session** — the LLM maintains style consistency within a session better than across sessions
2. **Start with GFX-ONBD-008 (industry icons)** — these are the hardest to get right culturally. Once you nail the style, use it as a reference for all others
3. **Generate character-heavy illustrations together** — GFX-AUTH-001, GFX-ONBD-001, GFX-ONBD-012, GFX-ONBD-019 all have people. Do them in one session for consistent character proportions
4. **Generate badge/icon sets in one batch** — GFX-DASH-005, GFX-DASH-006, GFX-GLOB-006, GFX-ONBD-009 are all small icons. Batch them together
5. **After each batch, check**: Same skin tone? Same face style (dot eyes)? Same color saturation? Same level of detail? Same line weight?

### Priority Order

**Phase 1 (Critical):** GFX-ONBD-008 (6), GFX-ONBD-010 (4), GFX-AUTH-005, GFX-ONBD-019, GFX-ONBD-012, GFX-AUTH-001
**Phase 2 (High Impact):** GFX-LAND-001 (4), GFX-LAND-002 (4), GFX-GROW-001 (5), GFX-DASH-001–004, GFX-VOICE-001, GFX-ONBD-015 (3)
