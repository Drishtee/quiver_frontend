## API Endpoints Used

### Authentication
- `POST /auth/send-otp/` - Send OTP to phone
- `POST /auth/verify-otp/` - Verify OTP and get JWT tokens

### Onboarding
- `POST /onboarding/start/` - Start onboarding session
- `POST /onboarding/update-field/` - Update single field
- `POST /onboarding/bulk-update-fields/` - Update multiple fields
- `POST /onboarding/submit/` - Submit onboarding

### Meetings
- `POST /meetings/create/` - Create meeting
- `GET /meetings/list/` - List meetings
- `GET /meetings/{id}/` - Get meeting details
- `GET /meetings/{id}/meet-link/` - **NEW: Get Google Meet link**
- `POST /meetings/{id}/cancel/` - Cancel meeting
- `POST /meetings/{id}/participants/add/` - Add participants

## Migration Notes

### From Twilio Video to Google Meet

**Before:**
```typescript
// Had to install twilio-video SDK
const { token } = await generateVideoToken(meetingId);
const room = await Video.connect(token);
// Complex track handling...
```

**After:**
```typescript
// Much simpler!
const { meet_link } = await getMeetLink(meetingId);
window.open(meet_link, '_blank');
// Or embed it:
<iframe src={meet_link} allow="camera; microphone" />
```
